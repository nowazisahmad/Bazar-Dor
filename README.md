# বাজার দর (BazarDor)

## 📖 Short Description
**বাজার দর (BazarDor)** is a modern, responsive web application designed to help users track daily market prices of essential commodities in Bangladesh. Users can easily view today's prices, compare them with yesterday's or last week's rates, and see a detailed breakdown of prices across different local markets (Bazar) and divisions. It provides a seamless way to stay informed about the fluctuating market conditions.

## 🛠️ Technologies Used
*   **Framework:** [Next.js](https://nextjs.org/) (App Router)
*   **UI Library:** [React](https://react.dev/)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/) (v4)
*   **UI Components:** [HeroUI](https://www.heroui.com/)
*   **Icons:** [Iconify](https://iconify.design/)
*   **Authentication:** [Better Auth](https://www.better-auth.com/)
*   **Data Source:** REST API (Programming Hero Open API)

## ✨ 5 Key Features
1.  **Daily Price Tracking & Trends:** View the current market price of various items along with a clear visual indicator (increase/decrease percentage) compared to the previous day.
2.  **Detailed Market Breakdown:** A comprehensive table that shows the minimum, maximum, and average prices of a specific product across different markets and divisions in Bangladesh.
3.  **Categorized Browsing:** Products are neatly organized into categories (e.g., Rice, Lentils, Oil, Vegetables) allowing users to quickly find the items they are looking for.
4.  **Secure User Authentication:** Includes a fully functional authentication system with Sign Up, Sign In, Google/GitHub OAuth, and a protected user profile page where users can update their information.
5.  **Fully Responsive UI:** The entire application is built with a mobile-first approach using Tailwind CSS, ensuring a seamless experience across mobile phones, tablets, and desktop computers.
